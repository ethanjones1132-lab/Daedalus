## Plan

**Data model.** The world is a `cells` array of length `width*height` (row-major: index `y*width+x`), each `{grass, rabbit, fox}` where `rabbit`/`fox` are `{id, energy}` or `null`. Two parallel arrays `rabbits` and `foxes` hold live animals with `{id, energy, x, y}`. A single `id` counter starts at 1 and increments for every animal created. `rand` is one `mulberry32(seed)` stream created in `reset`. `history` is an array of `{tick, rabbits, foxes, grass}`. `lab` state (`seed`, `params`, `speed`, `playing`, `raf`, `acc`, `lastTime`) is module-scoped.

**Tick order.** `reset(seed, params)` merges params over defaults, seeds `rand`, resets counters, fills grass row-major, places rabbits then foxes on empty cells via `pick`, records tick 0, redraws. One tick: (1) grass grows to `min(grassMax, grass+1)`; (2) rabbits processed in ascending-id order—move to a neighbour with no rabbit, eat grass, subtract cost, breed into a free neighbour (splitting energy), die at energy≤0; (3) foxes in ascending-id order—move toward a rabbit-free-of-fox, else any fox-free neighbour, eat a rabbit in the cell, subtract cost, breed, die; (4) `tick++`, record `{tick, rabbits, foxes, grass=sum}`. `step(n)` runs `n` ticks then updates canvas/chart/counters once.

**Components.** `world` panel: `<canvas data-testid="world">`, play/pause/step/reset buttons, seed number input, speed range, six parameter sliders (`rabbits0`, `foxes0`, `rabbitBreed`, `foxBreed`, `foxGain`, `grassMax`) each with `<label>` and value readout, and counters `tick`/`count-rabbits`/`count-foxes`/`count-grass`. `side` panel: `<svg data-testid="chart">` with `series-rabbits`/`series-foxes` polylines and axis labels, CSV export button, scenario tools (`scenario-json` textarea, export/load/error), Lotka–Volterra inputs (`ode-*`), `ode-run` button with outputs (`ode-x`/`ode-y`/`ode-eq-x`/`ode-eq-y`/`ode-drift`) and `ode-chart`, and presets (`preset-name`, `preset-save`, `preset-list` with `preset-item`s holding `preset-load`/`preset-delete`). An `announcer` with `aria-live="polite"` announces paused state. Keyboard shortcuts (Space/s/r) fire only when no control is focused. CSS uses flexbox: side-by-side at ≥1000px, stacked under 700px, canvas scaled to fit with no horizontal scroll.
