## Plan

**Data model.** One module-scoped world: `P` (13 params merged over `DEFAULTS` each reset), `W/H` grid size, a single `mulberry32(seed)` stream `rand`, `tickNum`, a `nextId` counter shared by both species, `grass` = `Int32Array(W*H)`, `rabbitGrid`/`foxGrid` = arrays of animal refs (or `null`), `rabbits`/`foxes` = arrays of live `{id,x,y,energy}` in id order, and `history` = `[{tick,rabbits,foxes,grass}]`. Neighbour indices are generated on demand in the fixed order up, right, down, left, clipped to the grid. `pick(list)` draws exactly one number and only when the list is non-empty.

**Tick order.** (1) every grass cell `min(grassMax, grass+1)`; (2) snapshot rabbits sorted by id and, for each: move to `pick(free neighbours)` else stay → eat `grass` of the new cell (set to 0) → pay cost → if `energy >= rabbitBreed` pick a free neighbour, split energy, spawn child with next id → remove if `energy <= 0`; (3) same for foxes, but move prefers neighbours holding a rabbit and no fox, then any fox-free neighbour, then eats any rabbit in the cell, then cost, breed, die; (4) `tickNum++` and push a history point.

**Components.** Sim core (`reset`, `oneTick`, `counts`, `cell`, `history`, `exportCSV`, `exportScenario`, `loadScenario`, RK4 `integrate`/`ode`, `window.lab`); renderer (canvas cells → grass `rgb(30,G,30)`, white rabbit 6×6, orange fox 8×8 on top; SVG polylines for both charts); clock (`requestAnimationFrame` + timestamps, accumulator in ticks, speed read live, pauses cleanly); controls (play/pause/step/reset, seed, speed, 6 labelled parameter sliders with live value readouts, 4 counters); Lotka–Volterra panel (8 inputs, run button, final values, equilibria, drift, trajectory chart); scenario textarea + error line + CSV download; presets in `localStorage["ecolab.presets"]`; announcer `aria-live` showing `Tick N: R rabbits, F foxes` whenever paused; document-level Space/`s`/`r` shortcuts that stand down while any control has focus.
